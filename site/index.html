PRODUCT CAPABILITIES

围绕真实销售流程设计

减少工具切换，让线索来源、研究证据、沟通记录、商机进度和成交结果保持关联。

01

客户发现

连接搜索、官网、Google Places、行业名录、展会和公开采购来源，沉淀可追溯的企业线索。

02

AI 研究与评分

按 ICP 研究企业，展示匹配分、置信度、评分拆解和来源证据，支持人工修正。

03

客户工作台

统一管理企业档案、联系人、关系阶段、预估价值和下一步行动。

04

营销触达

通过 SMTP、SendGrid、Mailgun、合规 Webhook 和 WhatsApp 编排内容与跟进。

05

销售管道

跟踪商机阶段、任务、回复和成交，批量操作保留审批和审计记录。

06

转化与归因

比较渠道从发现、研究、触达到回复、商机和成交的转化表现与 ROI。

ONE CONNECTED WORKFLOW

每一步都有来源，
每个结果都能回看

从企业证据到最终收入，Sondara 保留完整上下文，让团队知道线索从哪里来、为什么值得跟进、哪个渠道真正带来成交。

RUN IT YOURSELF

几条命令，本地启动

需要 Node.js 24 LTS。SQLite 随项目使用，不需要单独安装数据库服务。

Terminal
git clone https://github.com/huangheng-dev/Sondara.git
cd Sondara
npm install
npm run setup -- --non-interactive
npm run start:local
