## 批量导入中心的产品原则

- 文件导入优先，官方 API 逐步增加
- 所有导入数据默认进入待验证，不直接自动群发
- 每条线索必须保留来源和原始记录
- 去重和合并必须可预览、可追溯、可审计
- 不导入来源不明的私人联系人数据
